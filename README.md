# NodeFlow - Traffic Simulation & Management Game

## Overview
NodeFlow is a real-time traffic simulation and management game inspired by Trafficer and TrafficerMC. Players can manage traffic flow, control AI vehicles, and simulate complex traffic scenarios using automation tools. The game is built on Node.js and features a custom scripting engine for automation.

## Features
- **Real-time Traffic Simulation**: Manage various vehicle types including cars, trucks, and emergency vehicles.
- **Automation Tools**: Utilize a custom scripting language to automate traffic management tasks.
- **Anti-AFK Mechanism**: Prevent idle states in the simulation to maintain dynamic traffic flow.
- **Customizable UI**: Load custom themes and styles for a personalized experience.
- **Multiplayer Support**: Compete with other players in various game modes.

## Technical Stack
- **Backend**: Node.js with Express.js
- **Real-time Communication**: Socket.io
- **Frontend**: HTML5 Canvas with custom CSS theming support
- **Data Storage**: JSON files with auto-save functionality

## Installation
1. Clone the repository:
   ```
   git clone https://github.com/yourusername/nodeflow.git
   ```
2. Navigate to the project directory:
   ```
   cd nodeflow
   ```
3. Install dependencies:
   ```
   npm install
   ```
4. Start the server:
   ```
   npm start
   ```

## Usage
- Access the game through your web browser at `http://localhost:3000`.
- Use the dashboard to manage traffic, view statistics, and run scripts.
- Customize your experience with the theme manager.
